# Passport Photo Sheet Maker

**Live: https://passport-photo-sheet.pages.dev/**

Make a printable A4 sheet of 30 passport size photos at home, then print it at any photocopy shop for about ₹10.

- Sizes: 35×45 mm (passport), 51×51 mm (US visa), stamp size
- Runs fully in the browser. Your photo never leaves your device.
- Works offline. Free.

## Run locally

Open `index.html` in a browser. No build step.

## Deploy

Pushes to `main` auto-deploy to Cloudflare Pages.
